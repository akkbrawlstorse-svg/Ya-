# AlightCut

Редактор в стиле CapCut с движком в духе Alight Motion. Один файл: `www/index.html`.

## Запуск без APK
Откройте `www/index.html` в Chrome на телефоне. Кнопка `+` справа на таймлайне открывает выбор файлов.

## Как получить APK (без Android Studio)
1. Создайте репозиторий на github.com и загрузите в него всё содержимое этой папки (вместе с `.github`).
2. Откройте вкладку **Actions → Build APK → Run workflow**.
3. Через 5–8 минут скачайте `AlightCut-debug-apk` из Artifacts, распакуйте и установите `app-debug.apk`.

Альтернатива: загрузите `www/index.html` на любой хостинг (GitHub Pages) и вставьте ссылку в pwabuilder.com.

## Что внутри
- Таймлайн, разделение, обрезка за края, магнит к битам и краям клипов
- Ключевые кадры (X, Y, масштаб, поворот, прозрачность) с кривыми Безье, Hold, Bounce, Elastic
- 16 режимов наложения
- ~60 работающих эффектов (каталог из ваших списков, остальные помечены «скоро»)
- Авто-бит: анализ аудио, маркеры, нарезка по битам, пульс по битам
- XML Alight Motion: импорт и экспорт (`<scene>`, `<bookmark>`, ключи, эффекты, вложенные сцены разворачиваются в плоские слои)
- Экспорт видео через MediaRecorder (MP4 или WebM, зависит от телефона)

## Ограничения
- Эффекты 3D-камеры, mesh warp, векторное рисование, текст по контуру, родительские связи, группы пока не реализованы.
- Размер текста из XML подбирается приблизительно, настраивается в «Редагувати».
- Файлы в XML ссылаются на внутренние ресурсы Alight Motion, их нужно указать заново во вкладке «Медіа».
